Git

  • git init - команда для создания нового репозитория Git в текущей папке.
  • git clone - команда для создания копии существующего репозитория на локальном компьютере.
  • git status - команда для просмотра текущего состояния репозитория: какие файлы изменены и подготовлены к коммиту.
  • git add - команда для подготовки файлов к коммиту (добавления изменений в индекс).
  • git commit -m "сообщение" - команда для сохранения изменений в локальном репозитории с кратким описанием.
  • git push - команда для отправки локальных коммитов в удалённый репозиторий (например, на GitHub).
  • git pull - команда для получения изменений из удалённого репозитория и слияния их с локальной версией.
  • git branch - команда для просмотра списка веток или создания новой ветки.
  • git checkout - команда для переключения между ветками или восстановления файлов.
